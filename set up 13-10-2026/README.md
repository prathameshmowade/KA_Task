## How to Compile & Run

### 1. Run the All-in-One Program
```bash
javac Hello.java
java Hello
```

### 2. Run Individual Programs
```bash
javac HelloWorld.java && java HelloWorld
javac Addition.java && java Addition
javac Difference.java && java Difference
javac Multiplication.java && java Multiplication
javac Division.java && java Division
javac Modulus.java && java Modulus
```
