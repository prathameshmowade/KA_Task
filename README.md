# Kiran Academy - Daily Practice (Day: 5-10-26)

This repository contains solutions for Python programming practice tasks.

## Tasks Included

1. **Hello World with Name** (`task1_hello_world.py`)
   - Program to display "Hello World ... by [Your Name]".
2. **Profit or Loss Calculator** (`task2_profit_loss.py`)
   - Calculates profit or loss along with percentage given `cost_price` and `selling_price`.
3. **Odd or Even Checker** (`task3_even_odd.py`)
   - Checks whether an input integer is odd or even.
4. **Voting Eligibility & Age Validation** (`task4_voting_eligibility.py`)
   - Validates if the entered age is realistic (0 to 120) and checks whether the person is eligible for voting (age >= 18).
5. **Anagram Checker** (`task5_anagram.py`)
   - Determines whether two words are anagrams of each other.

## How to Run

To run all tasks at once:
```bash
python solutions_simple.py
```

To run individual tasks:
```bash
python task1_hello_world.py
python task2_profit_loss.py
python task3_even_odd.py
python task4_voting_eligibility.py
python task5_anagram.py
```
